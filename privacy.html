隱私權政策 / Privacy Policy

生效日期 / Effective date: 2026-11-26

中文

Shorts Studio Backup 是擁有者本人使用的備份設定，沒有其他使用者。

  • 存取的資料：它只要求 Google 雲端硬碟的 drive.file 權限，也就是只能讀寫由它自己建立或上傳的檔案。它看不到帳號裡其他的檔案。
  • 資料的用途：把擁有者電腦上的影片專案檔上傳到擁有者自己的 Google 雲端硬碟存檔，以及之後取回。
  • 資料的存放：檔案只存在擁有者的電腦和擁有者的 Google 雲端硬碟。授權憑證只存在擁有者的電腦上。沒有任何其他伺服器。
  • 資料的分享：不收集、不出售、不分享任何資料給第三方。
  • 撤銷授權：擁有者可以隨時在 Google 帳戶的「第三方應用程式和服務」頁面移除這個應用程式的存取權。

English

Shorts Studio Backup is a backup setup used by its owner only. It has no other users.

  • Data accessed: it requests only the Google Drive drive.file scope, so it can read and write only the files it created or uploaded itself. It cannot see any other file in the account.
  • Use of data: uploading the owner's own video project files from the owner's computer to the owner's own Google Drive for archiving, and retrieving them later.
  • Storage: files exist only on the owner's computer and in the owner's Google Drive. The authorization token is stored only on the owner's computer. No other server is involved.
  • Sharing: no data is collected, sold or shared with any third party.
  • Revoking access: the owner can remove this app's access at any time on the "Third-party apps and services" page of the Google Account.
